# Deep Tabular Learning

**Deep Tabular Learning** is an academic project developed as part of the **Deep Learning course** at the **Faculty of Computers and Artificial Intelligence, Capital University**.

The project focuses on implementing, evaluating, and improving **Artificial Neural Network (ANN)** models for tabular data, inspired by the research paper:

📄 **[Revisiting Deep Learning Models for Tabular Data](https://arxiv.org/abs/2106.11959)**

Our main objective is to reproduce a neural network approach presented in the research, explore potential architectural and training improvements, and evaluate whether these modifications can enhance model performance.

We aim to conduct a fair comparison between the **original implementation and our proposed improvements** using consistent evaluation metrics and experimental settings.
